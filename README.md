# 一起说英语 PWA

这是“奶奶和宝宝一起学英语”的第一个可运行版本，包含两周十四个不同主题。第二周会在首页下方以灰色预告出现，并在第 8 天自动开启。

## 已完成

- 每天约 30 分钟，分成两个约 15 分钟的时间段
- 第一段增加四轮单词听辨，图片顺序会变化，避免点一次就结束
- 第二段会把两句日常用语按正常、慢速分别听完并跟读
- 双人小剧场每一句都要先听再开口，不会再跳过对话
- 第二天第一段会先复习前一天，再学习当天的新内容
- 第一周包含问候、颜色、玩具、动物、穿衣、公园和家人
- 第二周包含整理、形状、动作、心情、天气、礼貌和房间寻宝
- 每周最后一天在完成两段学习后，会开启一个约 8 分钟的小火车特别版
- 第一周练习火车问候与上车，第二周扮演列车长练习快、慢、出发和停车
- 宝宝通过图片和声音学习生活单词
- 奶奶练习对应的日常句子
- 内置自然美式女声，所有课程离线时也能播放
- 每句话都有正常和慢速两份录音，慢速约为正常语速的一半
- 首页右上角显示离线内容加载进度，全部缓存后显示“加载完成”
- 两个人轮流完成四句角色对话
- 离开屏幕完成一个家庭真人任务
- 默认建议安排在上午自由活动后和下午亲子时间，吃饭时不学习、不提醒
- 学习进度保存在当前设备中
- 首页有“宝宝的奖励车厢”，完成过的课程会点亮并永久显示对应物品
- 重复完成同一课程会累计奖励次数，小火车特别版奖励也会进入车厢
- 第一次联网加载后可以离线使用
- 适配手机和平板，可添加到主屏幕

## 本地打开

在这个目录启动任意静态网页服务，然后用浏览器打开 `index.html`。语音播放和离线缓存需要通过 `http://` 或 `https://` 地址访问，直接双击文件时可能受到浏览器限制。

## 放到 NAS

与数独 PWA 一样，把整个文件夹上传到 NAS 的同一个 HTTPS 目录。用 Safari 打开页面，等待右上角显示“加载完成”，再从分享菜单选择“添加到主屏幕”。

更新应用文件后，需要同时修改 `sw.js` 里的 `CACHE_NAME`，让已经安装的设备获取新版本。
